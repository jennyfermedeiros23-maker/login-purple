💜 Login Purple

Uma interface de login desenvolvida com HTML5 e CSS3, com uma identidade visual inspirada em tons de roxo, paisagens noturnas e fantasia.

✨ Sobre o projeto

O objetivo foi desenvolver uma tela de login com uma aparência moderna e delicada, utilizando cores, transparências e elementos visuais personalizados.

🎨 Características

- Campo de usuário.
- Campo de senha.
- Opção de lembrar senha.
- Link para recuperação de senha.
- Botão de login.
- Link para cadastro.
- Efeitos de interação com CSS.

🛠️ Tecnologias utilizadas

- HTML5
- CSS3

📂 Arquivos do projeto

- "index.html" — estrutura da página.
- "styles.css" — estilização da interface.
- "img.jpg" — imagem utilizada no projeto.

🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo "index.html" utilizando o Live Server.

Projeto desenvolvido como prática de estudos em desenvolvimento web.
